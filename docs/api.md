# API

- `GET /api/jobs` and `GET /api/jobs/:slug`
- `GET /api/companies`
- `GET /api/locations`
- `GET`, `POST`, and `DELETE /api/saved-jobs`
- `POST /api/calculators`
- `POST /api/auth/login`, `POST /api/auth/signup`, and `POST /api/auth/logout`

Saved-job and authentication operations require the signed session cookie.
